Ejecuta un ciclo completo de póliza

Una ejecución crea una póliza sintética, la activa, demuestra el rechazo de una escritura con versión obsoleta, la cancela y recupera su historial de auditoría. No es una simulación en el navegador: cada paso es una operación real contra SQL Server.

Reproduce la ejecución desde tu terminal

El endpoint es anónimo, no acepta cuerpo de petición y está limitado por ventana fija. No hace falta confiar en esta página. 

curl -i -X POST "https://nain-policy-demo-api.azurewebsites.net/api/v1/demo/run" -H "Accept: application/json"

Plan gratuito por diseño: Azure App Service F1 y Azure SQL Free con AutoPause. La primera petición tras un periodo de inactividad despierta la base de datos y puede tardar bastante más que las siguientes. No hay SLA y el coste incremental autorizado es 0 EUR.

Datos sintéticos. Sin datos personales. Los endpoints de negocio siguen protegidos por JWT y roles. Límites y configuración verificada ↗
